# VOICEVOX読み上げプラグイン

受信したコメントを [VOICEVOX](https://voicevox.hiroshiba.jp/) の音声で読み上げるプラグインです。棒読みちゃんなしで MCV 単体で読み上げができます。

## 使い方

1. VOICEVOX（アプリ版またはエンジン単体）を起動しておく（既定で `http://localhost:50021` で待ち受けます）
2. MCV のメニュー「プラグイン」→「VOICEVOX読み上げ」で設定画面を開く
3. 「接続テスト・話者一覧を取得」を押して、話者を選ぶ（既定は冥鳴ひまり（ノーマル））
4. 「テスト再生」で声を確認し、「コメントをVOICEVOXで読み上げる」にチェックを入れる

> 棒読みちゃん連携プラグインも有効になっていると二重に読み上げます。棒読みちゃん連携の「棒読みちゃんにコメントを読んでもらう」はオフにしてください。

## 設定項目

| 項目 | 内容 |
|---|---|
| URL | VOICEVOXエンジンのURL |
| 話者 | 読み上げに使う声（スタイル） |
| 話速・音高・抑揚・音量 | VOICEVOX の各パラメータ |
| 出力先 | 再生するオーディオデバイス。OBS で読み上げだけ別トラックにしたい場合は仮想オーディオデバイス（VB-CABLE など）を選ぶ |
| 名前も読み上げる / 敬称 | 「〇〇さん、コメント」の形で読む。コテハンが設定されていればコテハンを使う |
| URLを「URL省略」と読む | URLをそのまま読み上げない |
| 184コメントも読み上げる | ニコ生の匿名コメント |
| 最大文字数 | 超えた分は「以下略」 |
| 読み上げ待ちの上限 | コメントが溜まりすぎたら古いものから捨てる |

NGユーザーのコメントと、接続直後に取得される過去のコメントは読み上げません。

## しくみ

- `SpeechQueue` が読み上げ要求を1件ずつ「合成（`/audio_query` → `/synthesis`）→ 再生」する。処理は1本だけなので音声は重ならない
- 再生は NAudio（`WaveOutEvent`）で、再生が終わってから次の合成に進む
- 設定は `settings/VOICEVOX読み上げ.xml` に保存される

## クレジット表記

VOICEVOX の音声を配信・動画で使う場合は、キャラクターごとの利用規約に従い「VOICEVOX:冥鳴ひまり」のようなクレジット表記が必要です。
